# Desenvolvimento Mobile II

Este repositório reúne as atividades práticas desenvolvidas durante o 5º semestre do curso de Desenvolvimento de Software Multiplataforma (DSM), na disciplina de Desenvolvimento Mobile II.

Os projetos são exercícios de desenvolvimento de aplicativos móveis com React Native e Expo. Cada atividade fica em sua própria pasta e pode ser executada de forma independente.

| Pasta | Atividade |
| --- | --- |
| [atividade_pratica_02painelsenha](./atividade_pratica_02painelsenha/) | Painel de senha |
| [atividade-pratica-05_palindromos](./atividade-pratica-05_palindromos/) | Verificação de palíndromos |
| [atividade-pratica-06---tematico](./atividade-pratica-06---tematico/) | Aplicativo temático de World of Warcraft |
| [atividade-pratica-07---cardapio](./atividade-pratica-07---cardapio/) | Cardápio |

| [atividade-pratica-11---dama](./atividade-pratica-11---dama/) | Jogo de damas |

## Como executar uma atividade

É necessário ter o Node.js e o npm instalados. No terminal, entre na pasta da atividade desejada e execute:

```bash
npm install
npm start
```

O Expo iniciará o projeto e exibirá opções para abrir o aplicativo em um dispositivo ou emulador.
